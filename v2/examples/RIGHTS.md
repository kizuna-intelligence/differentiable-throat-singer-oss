# Example provenance

`ievan_allvoice/song.json` uses the traditional Finnish Ievan polkka melody with Japanese lyrics authored for this project and a project-authored all-voice accompaniment. It does not include Eino Kettunen's Finnish lyrics, translations, Loituma's recording, arrangement or scat. The project source records this authorship; this is not a separate clearance of every possible arrangement claim. See [Loituma's history](https://www.loituma.fi/en/ievan-polkka-en/) for the distinction between the traditional melody and later lyrics.

`ievan_allvoice/trial_3_4.json` is an authored 3/4 scale/harmony test. Neither example comes from the singing database scores or lyrics. No generated audio/video is distributed.
