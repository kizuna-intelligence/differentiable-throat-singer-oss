# songkit

A score specification drives independent physical throats, accompaniment patterns, mixing and saved-state video replay. See [v2 installation and commands](../../README.md). From v2, run `python scripts/make_throat_song.py examples/ievan_allvoice/trial_3_4.json --out outputs/trial --audio-only` for synthesis/mixing, or omit `--audio-only` after installing the visualizer dependencies.

The video always carries `Visualization: CHIMERA vocal synth © 2026 Jameson Hodge (MIT)` at bottom right. The project-authored kana rules and numerical pitch sanity check need no external dictionary or pretrained evaluation weights. The latter is not the historical evaluator. Results remain Stage 3 unaccepted.
